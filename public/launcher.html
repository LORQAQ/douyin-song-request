一键启动向导 · 抖音点歌 → B站音乐

你用的是抖音直播伴侣（没有浏览器源），所以音乐是通过「虚拟声卡」送进直播伴侣的。 下面 4 步做完就能全自动跑起来，之后每次开播只要点一次「启动」。

整体链路

音乐从B站到你的直播间，中间经过这些环节：
抖音弹幕「点歌 晴天」
   ↓  （本程序监听弹幕）
B站搜索并挑出最合适的 MV / 音频
   ↓
本机「音乐播放页」在专用 Chrome 里播放（这个页面出声）
   ↓  （Chrome 的音频输出被指定到虚拟声卡）
VB-CABLE 虚拟声卡：CABLE Input → CABLE Output
   ↓
直播伴侣：麦克风/音频输入 选「CABLE Output」
   ↓
直播间观众听到音乐

第 1 步 · 打开音乐播放页 必须一直开着

这个页面负责出声。它是独立页面，即使关掉控制台，只要它开着音乐就不会断。
提示：请把它放在不会被关掉的位置（最小化即可）。页面右上角有「下一首」和「静音」。

第 2 步 · 把音乐送进虚拟声卡 只需设置一次

这是最关键的一步。推荐用播放页自带的「输出设备」按钮——Chrome 会记住这个选择， 以后开播都不用再设置，也不会影响你自己听歌。
  1. 打开 音乐播放页
  2. 点右上角的 🔈 输出设备 按钮
  3. 它会自动帮你切到 VB-Audio Virtual Cable，并弹提示确认
  4. 播放页上会显示一行绿字：✅ 已指向虚拟声卡，直播伴侣可以读到了
⚠️ 这行字必须是绿的。还是黄色就说明 Chrome 没在读虚拟声卡，观众听不到。
备选做法（如果播放页那个按钮不灵）： 右键任务栏喇叭 → 声音设置 → 音量合成器 → 找到正在放音乐的 Chrome → 把「输出设备」改成 VB-Audio Virtual Cable。
重要：Windows 的默认播放设备请保持你的耳机/音箱，不要设成虚拟声卡， 否则你自己就听不到声音了。我们只改 Chrome 这一路。

关于「你自己平时用的 Chrome」

程序用的是独立的 Chrome 实例 + 独立配置目录（.chrome-player-profile）， 和你平时上网的 Chrome 完全是两套，互不影响：
  • ✅ 你不开专用播放器，平时照样用 Chrome 上网、看视频
  • ✅ 两个可以同时开着，登录状态、插件、历史记录互不干扰
  • ✅ 只有专用播放器窗口会把声音送去虚拟声卡；你自己那个 Chrome 仍然走耳机/音箱
  • ✅ 关掉专用播放器只是停音乐，不影响你自己的浏览器
想区分两个窗口？专用播放器的窗口标题会显示 🔊 音乐播放页 · 设备名： 🔊 表示已经送到虚拟声卡，🔈 表示还没设置好。
⚠️ 别去 Windows「音量合成器」里把 Chrome 整体改到虚拟声卡——那会连你自己看视频的声音也一起送进直播间。 用播放页里那个「🔈 输出设备」按钮，它只改这一个窗口。

第 4 步 · 让观众看到播放列表 可选 · 需另装

观众能实时看到「谁点了什么歌」「还有几首在排队」，直播间会热闹很多。 做法是加一个背景透明的悬浮窗，直播伴侣把它叠在画面上。
歌单悬浮窗是一个独立的小程序，不随本程序分发。 它跟这个点歌程序是分开的两个东西 —— 点歌不需要它，装了它观众才能看到歌单。
获取方式（源码、文档、编译脚本都在仓库的 overlay/ 目录里）： 
源码与文档  https://github.com/LORQAQ/douyin-song-request/tree/main/overlay
预编译程序  https://github.com/LORQAQ/douyin-song-request/releases/latest
把源码里的 *.cs 和 build.bat 放到本程序的 overlay\ 目录， 双击 build.bat 编译（用 Windows 自带的 C# 编译器，不用装任何 SDK）； 或者直接从 Release 下载编译好的 exe 放进 overlay\bin\。
  1. 按上面的方式拿到悬浮窗，双击 SongOverlay.exe 启动
  2. 回到 直播伴侣 → 添加素材 → 选「窗口捕获」（有的版本叫「窗口」）
  3. 在窗口列表里选标题为「歌单悬浮窗」的那个窗口
  4. 拖动缩放和摆放位置（一般放左侧或右下角，别挡住你的脸）
可调的样子（用命令行参数）： 
SongOverlay.exe --max 8            最多显示 8 首待播（默认 6）
SongOverlay.exe --left 40 --top 600  指定位置
SongOverlay.exe --fixed            关掉鼠标穿透（能直接用鼠标拖）
完整参数、快捷键、通信协议见仓库里的 overlay/README.md。
⚠️ 如果窗口捕获出来背景是黑的（不是透明），说明这个捕获方式不支持透明。 试试换成「游戏源」，或者加 --fixed 重启悬浮窗。 实在不行就跑一下它自带的 WinDiag.exe，它会列出所有能被捕获的窗口及属性。
悬浮窗会自动跟随：当前歌、点歌人、待播队列实时更新，不用管它。 它连的是本机服务，不占网速也不影响播放。

第 3 步 · 直播伴侣里加一路音频

让观众听到音乐，同时不影响你自己的人声。
  1. 打开抖音直播伴侣 → 添加素材 / 添加音频（不同版本叫法略有差异）。
  2. 音频来源优先选 「系统声音 / 扬声器」。
  3. 如果只给「麦克风」选项：选 CABLE Output (VB-Audio Virtual Cable)。
  4. 把这一路音量调到合适（建议 60%~80%），别盖过你说话的声音。
  5. 自己开个小号进直播间听一下，确认：说话正常、音乐正常、没有回声/电流声。
⚠️ 常见坑：如果直播伴侣的「系统声音」把你自己的麦克风也录进去了，会形成回声。把这一路的监听关掉，并确认系统默认录音设备仍是你的麦克风。

第 4 步 · 开播前自检

  1. 控制台左上角「弹幕」应是绿色已连接；如果是灰色/红色，点「重连弹幕」。
  2. 在直播间用小号发一句：点歌 晴天。
  3. 控制台应出现「🎵 xxx 点歌：晴天」，队列里出现匹配到的B站视频。
  4. 音乐播放页开始出声，直播伴侣的电平表应该跳动。
建议再顺手做一次：npm run doctor，它会检查直播间、B站接口、Cookie 状态。

可选 · 直播伴侣小窗（浏览器插件）

想在直播伴侣里用浏览器素材显示「当前歌曲 / 下一位」，或者单纯想让弹幕抓取更快， 可以装这个扩展：它会在 live.douyin.com 页面上读弹幕并直接推给本程序，还会显示一个悬浮小窗。
  1. 解压 zip 到任意目录（例如 D:\dsh-extension）。
  2. Chrome 打开 chrome://extensions → 右上角打开开发者模式 → 「加载已解压的扩展程序」→ 选解压出来的目录。
  3. 在直播伴侣里添加「浏览器」素材，地址填 https://live.douyin.com/你的直播间号 即可，小窗会自己出现。
注意：这个扩展只是「加速/展示」用途。不装它，本程序自己也能通过协议直连或浏览器兜底抓弹幕。
